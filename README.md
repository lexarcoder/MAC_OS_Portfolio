# 🖥️ Portfolio 2.0

> A modern macOS-inspired developer portfolio built with **React & Vite**, designed to feel like a desktop rather than a traditional website.

## ✨ Highlights

* 🖥️ macOS-inspired interactive desktop UI
* 🪟 Draggable & resizable application windows
* 🚀 App-style navigation and interactions
* 💻 Built-in developer terminal
* 🎨 Modern dark UI with SCSS
* ⚡ Smooth animations with Framer Motion
* 📝 Markdown & syntax-highlighted code
* 📱 Fully responsive design

## 🛠️ Tech Stack

**React 19 · Vite · SCSS · Framer Motion · React RND · React Markdown · React Syntax Highlighter · React Console Emulator**

## 🚀 Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/portfolio-2.0.git
cd portfolio-2.0
npm install
npm run dev
```

## 📦 Production Build

```bash
npm run build
```
